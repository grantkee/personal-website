Selected work

01

Migrate a live ERC20 token as the native token on its own Layer 1

TEL upgrade & migration

Architected and executed the migration end to end - governance, exchanges, liquidity, deployment - without breaking market continuity.

A non-standard two-decimal ERC-20 split across Ethereum and Polygon became one standardized token with a fixed 100B cap, deployed via CREATE3 to a mined vanity address under Safe multisig custody. Authored the TelIP and TGIP proposals that carried it through decentralized governance; built the native bridge adapter that lets the L1 verify external TEL.

CREATE3 Safe multisig TelIP · TGIP Native bridge
02

Built a blockchain secured by mobile carriers

Telcoin Network

Leads development of an EVM-compatible Layer 1 whose validator set is drawn exclusively from GSMA mobile network operators.

Directs protocol engineering across consensus, execution, networking, data availability, and validator infrastructure, plus the interfaces binding protocol to platform. Owns provider strategy - evaluating, onboarding, and maintaining the infrastructure partners standing the network up - and the explorer and observability tooling that keeps it legible.

Consensus Rust Validator ops GSMA operators
03

Took single hardware keys out of the critical path

Deployment architecture

Designed a multisignature deployment model so no individual key holder can unilaterally control production contracts or infrastructure.

Led engineers to a standardized workflow on Safe multisig wallets, Safe Utils, and CREATE3: deterministic addresses across EVM networks, ownership held by the safe from the first transaction. Thresholds and signer distribution designed for organizational control and continuity; tooling built along the way contributed back to Safe Utils.

Safe Utils Hardware custody Deterministic deploys
04

Made adversaries part of the process

Security program

Owns vulnerability discovery: competitive research, third-party audits, internal review, and continuous monitoring.

Coordinated a four-week open competition with more than $180,000 in prizes and runs the audit and remediation cycle gating production. Architected emergency on-chain controls - monitoring, pause and unpause paths that preserve governance - and authored the risk-assessment, incident-response, and protocol "code red" procedures behind them.

Audits Incident response Emergency controls
