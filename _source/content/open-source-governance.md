### Open-Source Engineering & Repository Governance

- **Own the GitHub engineering infrastructure for the Telcoin Association**, overseeing the organization's open-source repositories, development workflows, access controls, security configuration, and software-development governance.

- **Manage and maintain open-source projects under MIT and Apache 2.0 licensing**, ensuring repositories are structured and governed appropriately for public collaboration, redistribution, and downstream adoption.

- **Oversee the complete pull-request and issue-management lifecycle**, including creating and triaging issues, reviewing and coordinating pull requests, managing development workflows, and maintaining engineering standards across repositories.

- **Establish and maintain repository security controls**, including security advisories, vulnerability reporting processes, access permissions, user and organization tokens, repository policies, and other GitHub security parameters.

- **Manage GitHub Actions and automated development infrastructure**, overseeing CI/CD workflows, automated testing, build pipelines, validation processes, and other automation supporting reliable software delivery.

- **Maintain engineering documentation and contributor standards**, including README files, contribution guidelines, security policies, SECURITY.md documentation, development instructions, and repository-level technical documentation.

- **Oversee organizational identity and access management within GitHub**, controlling membership, repository permissions, administrative access, authentication mechanisms, and least-privilege access to critical development infrastructure.

- **Establish security and quality gates for open-source development**, integrating automated testing, code review, vulnerability management, and repository security practices into the software-development lifecycle.

- **Maintain the operational integrity of the organization's public engineering footprint**, ensuring repositories remain secure, documented, reproducible, actively maintained, and accessible to external developers and security researchers.
